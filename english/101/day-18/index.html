✏️ ব্যাকরণ টিপ

because / so / but — কারণ, ফল, বিপরীত

  • because — কারণ বলে: I am tired because I worked all day.
  • so — ফল বলে: I am tired, so I will sleep early.
  • but — বিপরীত বলে: It is nice, but it is far.
শুরুবসবেউদাহরণ
becauseকারণI stayed home because it rained.
soতাইIt rained, so I stayed home.
butকিন্তুI like tea, but I prefer coffee.
🧠 নিজে চেষ্টা করুন: I am tired, ___ I will sleep early.
because / so / but

উত্তর: so — ক্লান্ত → তাই ঘুমাব: ফল বোঝাতে so।
