✏️ ব্যাকরণ টিপ

I like বনাম I would like

  • I like — আমি পছন্দ করি (সাধারণ কথা): I like tea.
  • I would like — আমি চাই/নিতে চাই (ভদ্র অনুরোধ, অর্ডারের সময়): I would like some tea.
শুরুবসবেউদাহরণ
I like tea.আমি চা পছন্দ করিস্বভাব/পছন্দ
I would like tea.আমি চা নিতে চাইভদ্রভাবে চাওয়া
🧠 নিজে চেষ্টা করুন: Waiter: What would you like? You: I ___ like some rice.
will / would / am

উত্তর: would — ভদ্রভাবে চাইতে would like।
