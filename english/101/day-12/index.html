✏️ ব্যাকরণ টিপ

this / that / these / those

  • this — কাছের একটি জিনিস: this shirt
  • these — কাছের অনেকগুলো: these shoes
  • that — দূরের একটি: that bag
  • those — দূরের অনেকগুলো: those trousers
শুরুবসবেউদাহরণ
thisকাছে, একটিThis shirt is nice.
theseকাছে, একাধিকThese shoes are new.
thatদূরে, একটিThat bag is big.
thoseদূরে, একাধিকThose books are old.
🧠 নিজে চেষ্টা করুন: (হাতের কাছের অনেক জুতা) ___ shoes are comfortable.
This / These / That

উত্তর: These — কাছে + একাধিক = these।
